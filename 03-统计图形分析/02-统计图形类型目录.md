# RAWGraphs｜统计图形类型目录

## 一、目录说明

RAWGraphs App 的 `src/charts.js` 登记了 **32 个内置图表实现**：其中 31 个来自 `@rawgraphs/rawgraphs-charts`，另有 `calendarHeatmap` 来自独立的 `@rawgraphs/rawgraphs-calendar-heatmap` 包。

下列英文名称以图表 metadata 为主要依据。分类标签保留源码中的类别词，含义相同的图表可以同时属于多个标签。它们是程序界面的筛选标签，不是严格互斥的学术分类。

## 二、按官方类别标签整理

### 1. Correlations｜关联／关系

- Bar chart｜条形图：用条形长度表达类别对应的数量。
- Multi-set bar chart｜多组条形图：在类别组内并列比较多个数量维度。
- Stacked bar chart｜堆叠条形图：在类别组内堆叠多个数量维度。
- Bubble chart｜气泡图：以二维位置表达两个连续变量的关系，并可用尺寸、颜色编码附加变量。
- Bumpchart｜排名变化图：比较多个类别在连续维度上的排序变化。
- Contour plot｜等高线图：估计点云密度，帮助处理大量点重叠。
- Convex hull｜凸包图：用凸包边界识别散点图中属于同一类别的点群。
- Gantt chart｜甘特图：以时间区间和条形展示项目任务的开始与结束。
- Hexagonal binning｜六边形分箱图：将点归入六边形网格，以颜色或面积表示每个网格中的点数量。
- Horizon graph｜地平线图：显示连续区间或时间上的数值变化，结合位置与颜色压缩垂直空间。
- Line chart｜折线图：显示连续区间或时间上的数量变化，可用颜色增加分类或数量维度。
- Matrix Plot｜矩阵图：将两个分类维度置于横纵轴，以方形／圆形符号及尺寸、颜色表示关联变量。
- Parallel coordinates｜平行坐标图：多个连续维度分别作为平行轴，每条记录形成一条跨轴折线。
- Radar Chart｜雷达图：多个连续维度从共同中心向外放射，使用同一尺度比较维度值。
- Slope chart｜斜率图：用两个连续维度的轴和连接线表达两端数值关系。
- Streamgraph (area chart)｜流图／面积图：比较多个类别在连续维度上的变化。
- Voronoi Diagram｜Voronoi 图／泰森多边形图：以两个变量定义点周围的最小区域，显示点之间的空间邻近关系。

### 2. Proportions｜比例／构成

- Alluvial Diagram｜冲积图：以流带展示多个分类维度之间共享项目的流动关系，流带宽度与数值相关。
- Multi-set bar chart｜多组条形图。
- Stacked bar chart｜堆叠条形图。
- Beeswarm plot｜蜂群图：以点的位置分布呈现连续维度上的项目分布，点面积和颜色可编码附加变量。
- Bubble chart｜气泡图。
- Bumpchart｜排名变化图。
- Circle Packing｜圆形填充图：用嵌套圆展示层级结构，叶节点圆面积表达数值。
- Circular dendrogram｜圆形树状图：以径向树结构展示层级数据。
- Convex hull｜凸包图。
- Matrix Plot｜矩阵图。
- Pie chart｜饼图：以圆弧／扇区表达部分与整体的比例。
- Streamgraph｜流图／面积图。
- Sunburst diagram｜旭日图：以同心圆环展示层级结构，扇区角度与数值相关。
- Treemap｜矩形树图：以嵌套矩形展示层级结构，矩形面积对应数值。
- Treemap (Voronoi)｜Voronoi 矩形树图：以 Voronoi 单元替代矩形表达层级结构；源码说明面积可能不能完全代表映射值。

### 3. Distributions｜分布

- Beeswarm plot｜蜂群图。
- Box plot｜箱线图：以最小值、下四分位数、中位数、上四分位数、最大值概括数值分布。
- Contour plot｜等高线图。
- Hexagonal binning｜六边形分箱图。
- Parallel coordinates｜平行坐标图。
- Violin plot｜小提琴图：以形状宽度表示相同数值附近的数据量。

### 4. Time series｜时间序列

- Beeswarm plot｜蜂群图。
- Bumpchart｜排名变化图。
- Gantt chart｜甘特图。
- Horizon graph｜地平线图。
- Line chart｜折线图。
- Matrix Plot｜矩阵图。
- Streamgraph｜流图／面积图。
- Calendar Heatmap｜日历热力图：来自独立的 calendar-heatmap 包；以日历布局呈现时间相关数值。

### 5. Networks｜网络

- Arc Diagram｜弧线图：节点排列在水平轴上，以弧线连接节点表达关系方向。
- Chord Diagram｜弦图：节点围绕圆周排列，以弦连接节点表达关系及其数值。
- Sankey Diagram｜桑基图：以节点和具有宽度的曲线表达网络中的流量。

### 6. Hierarchies｜层级

- Circle Packing｜圆形填充图。
- Circular dendrogram｜圆形树状图。
- Linear dendrogram｜线性树状图：以树结构展示层级关系，根节点位于左侧、叶节点位于右侧。
- Sunburst diagram｜旭日图。
- Treemap｜矩形树图。
- Treemap (Voronoi)｜Voronoi 矩形树图。

## 三、按视觉结构进一步理解（研究归纳）

以下是便于分析的二次归纳，不是 RAWGraphs metadata 的官方分类：

| 视觉结构 | 代表图形 | 主要表达任务 |
| --- | --- | --- |
| 位置／坐标 | 折线图、气泡图、斜率图、平行坐标图 | 变量关系、趋势、变化 |
| 长度／方向 | 条形图、堆叠条形图、甘特图 | 数量比较、构成、时间区间 |
| 面积／区域 | 饼图、矩形树图、圆形填充图 | 部分整体、层级规模 |
| 点群／密度 | 蜂群图、箱线图、小提琴图、等高线图、六边形分箱图 | 分布、聚集、离散 |
| 连线／流带 | 弧线图、弦图、桑基图、冲积图 | 网络关系、流向、分类转移 |
| 树／层级 | 树状图、旭日图、圆形填充图、矩形树图 | 父子关系、嵌套结构 |
| 时间布局 | 日历热力图、地平线图、流图、甘特图 | 时间分布、周期、过程 |

## 四、分类使用提醒

1. 一个图形可以同时服务于关系、比例、分布或时间序列等任务，不能只凭外形给它归入唯一类别。
2. “图表名称”与“数据分析任务”不是同一概念。同一种视觉结构可能服务不同问题。
3. RAWGraphs 的官方类别标签是程序筛选机制；本目录的视觉结构表是研究者为学习和分析增加的归纳层。
4. 不要把 RAWGraphs 的 32 种内置图表误认为统计图形的全部种类。
