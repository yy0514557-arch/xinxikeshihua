## 五项分析维度

A 基本数据逻辑（数据结构）；B 统计图形、统计方法和计算；C 点、线、面、体、符号、色彩等视觉编码；D 数据／信息架构；E 视觉叙事架构。

## 案例持续更新机制

1. 用户提供案例图片，分配唯一编号 CASE-0001 起，原图只入 `02-信息图形类型案例/素材/`。
2. 按 [案例模板](02-信息图形类型案例/案例分析/案例模板.md) 编写逐图分析，区分观察、合理推断和待核查事项。
3. 将案例的相对路径链接登记到 02 内对应类型文档。单图可属于多种类型。
4. 将有依据的经验、限制条件及反例更新到 01 的对应逻辑文档，仅用文本内链接指向 02 的分析，不复制图片。
5. 多案例对照后才将结论升级为跨案例原则，保留修订时间和证据链。
