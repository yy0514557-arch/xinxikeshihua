# 信息可视化研究仓库

本仓库用于整理信息图形的数据逻辑、类型案例、统计图形、视觉感知规律与主题设计项目。

## 目录导航
- [01-信息图形数据逻辑](01-信息图形数据逻辑/README.md)：信息的数据组织逻辑。
- [02-信息图形类型案例](02-信息图形类型案例/README.md)：信息图形类型、案例与分析；ISOTYPE 作为基础设计方式独立标记。
- [03-统计图形分析](03-统计图形分析)：统计图形方法、数据表达与案例分析。
- [04-Gestalt格式塔视觉组织规律](04-Gestalt格式塔视觉组织规律/README.md)：视觉分组、图形与背景、形态完整、知觉影响因素及专题研究。
- [05-XXX主题信息图形设计](05-XXX主题信息图形设计/README.md)：可复制的主题信息图形设计项目模板。

## 研究边界
信息图形类型、数据逻辑、统计图形、Gestalt 视觉组织规律和 ISOTYPE 基础设计方式属于不同分析层次。案例可以跨层次关联，但不应混为同一分类。
