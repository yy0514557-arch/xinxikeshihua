# 04｜基础数据集构建

## 核心原则：字段原子化
一列只表示一个明确变量；一个单元格只保存一个数据值。每一行代表一个明确的数据对象／事件／观测记录。“只有 1 个数据”指每个单元格一个原子值，不是整张表只有一条数据。

允许的单元格值：名义数据（类别、名称、类型、状态）；量化数据（整数、小数、比例、金额、计数）；图像数据（一个图像路径／链接／资源 ID）；文本数据（一个独立文本条目、标题、摘要或摘录）。

## 字段规则
- 一列只放一种含义，不把姓名和年龄拼在一列。
- 经纬度拆为 latitude、longitude；不要把两个数放同一格。
- 多个标签拆成关联表或独立记录，不用逗号塞在一格。
- 多张图片每张单独一行或进入独立资源表。
- 日期、单位、币种、统计口径需明确记录；同列数值单位应统一。
- 文本摘录需关联来源 ID、页码／段落。

## 数据分层
1 原始数据；2 清洗数据；3 基础主表；4 关联资源表；5 叙事数据集。

## 交付物
基础表 CSV／XLSX、字段字典、清洗记录、数据质量报告、关联表与资源索引。

## 质量检查
每行记录单位一致；每列语义唯一；单元格只有一个值；单位统一；主键唯一；缺失值规则一致；来源可追溯。
