# 08｜设计实施

## 流程
1 设计定位：主题命题、受众、叙事、风格、输出场景。2 构图草图：画面比例、信息分区、阅读顺序、主视觉和信息密度。3 版式线框：标题、导语、主／辅信息、图例、注释、来源。4 视觉样式探索：色彩、字体、图像、图形、符号。5 内容置入：使用核验后的叙事数据，确保数值、标签、单位、来源一致。6 视觉精修：层级、对齐、留白、行距、字距、对比、图例和阅读路径。7 校对测试：事实、数据、文字、比例、版权、可读性、输出尺寸。8 定稿输出：可编辑源文件、屏幕／印刷文件、版本记录。

## 交付检查
主题与叙事是否清楚；数据与图片是否可追溯；图表是否忠实表达数据；层级和阅读顺序是否自然；文字、行距、字距与图例是否可读；版权许可署名是否齐备；输出尺寸、色彩模式、分辨率和格式是否符合场景。
