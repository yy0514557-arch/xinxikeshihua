# 03｜数据搜集

## 来源类型
1. 公用数据集：政府开放数据、国际组织、科研机构、公共数据库、开放 API 等。记录名称、发布机构、网址、下载日期、许可、更新时间、字段说明与统计口径。
2. 文本文献：论文、书籍、年鉴、报告、新闻档案、法规、地方志、访谈文本等。记录作者、出版信息、页码／段落、原文摘录、可提取字段与引用信息。
3. 自建数据集：实地观察、问卷、访谈、人工标注、图像采集、测量与编码等。记录方法、时间、地点、样本、采集者、授权、误差和局限。

每份来源记录编号、名称、发布者／作者、链接／出处、发布时间、获取日期、许可、范围、字段、口径、可信度和处理记录。

交付：来源清单、原始数据／文献、许可与引用记录、数据缺口清单、补采计划。原始文件只读保存，清洗版本进入下一阶段。
