# 05｜叙事框架搭建

从基础数据集中选择字段，建立明确叙事单元。基础数据集记录完整数据；叙事数据集围绕主题组织信息。

## 字段组合示例
- 名称 + GPS（latitude、longitude）→ 地图上的地点信息。
- 名称 + 数值 + 单位 + 地区 → 某地 GDP 或其他指标比较。
- 事件名称 + 日期 → 时间轴／编年叙事。
- 人物名称 + 身份 + 事件 + 日期 → 人物与事件档案。
- 类别 + 数值 + 时间 → 类别变化趋势。
- 来源对象 + 目标对象 + 数值 → 关系网络或流向图。
- 图片资源 + 对象名称 + 时间／地点 → 照片型叙事。

## 搭建步骤
明确核心问题；选择时间／空间／类别／比较／过程／关系／因果主线；选择字段并说明作用；确定信息单元；安排开场、主体、转折／对比和结尾；核实依据；形成叙事数据集并回链基础数据 ID。

交付：叙事主题句、结构图／大纲、字段组合表、叙事数据集、来源追溯。
