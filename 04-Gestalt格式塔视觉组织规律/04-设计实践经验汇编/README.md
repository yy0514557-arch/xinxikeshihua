# 04｜设计实践经验汇编

## 目的
记录 Gestalt 原则在真实信息设计项目中的决策、尝试、失败版本和适用边界。实践经验是可追溯的设计记录，不自动等同于心理学实验结论。

## 分类
1. 信息层级与分组
2. 版式与网格
3. 字体与文字排版
4. 图形与背景
5. 图标与符号系统
6. 统计图形与信息图形
7. 色彩与视觉识别
8. 交互与动态视觉
9. 综合设计方法

## 每条经验必须记录
原始项目/案例 ID、目标问题和受众、调整前版本、改动变量、调整后版本、对照条件、设计者观察、用户反馈、失败版本、可迁移条件和不适用边界。

## 证据纪律
“我认为更清楚”标为设计者判断；“多数受试者选择 A”须附测试方法和样本；“提高理解”需要与理解任务匹配的证据。不得将审美偏好包装成普遍定律。
