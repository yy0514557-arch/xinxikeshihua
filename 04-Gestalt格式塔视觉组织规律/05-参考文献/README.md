## 证据分级
- L1 文献证据：原始研究、同行评审综述或学术专著。
- L2 图像观察：作品中可直接核验的距离、边界、颜色、连线、轮廓与排列事实。
- L3 理论解释：将观察线索对应到知觉组织概念。
- L4 设计推断：理论迁移至具体场景的建议，须标记待验证。
- L5 用户/实验数据：明确任务、样本、测量与分析所得结果。

## 引用规范
为具体定义与理论判断标注直接相关文献；核对 DOI、年份和卷期页码；不把设计者经验写成心理学实验结论。
