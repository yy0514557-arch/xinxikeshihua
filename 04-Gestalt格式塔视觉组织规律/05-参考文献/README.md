## E. 文献使用规范
- 优先引用原始研究、同行评审综述和学术出版社资料。
- 设计教育网站只补充应用说明，不作为知觉机制的唯一证据。
- 每条规则只列直接相关来源，不机械复制全部参考书目。
- DOI、正式出版年份、在线发表日期、页码及访问日期均须核验。
- 未核实字段标记“待核验”，不得猜测补齐。
