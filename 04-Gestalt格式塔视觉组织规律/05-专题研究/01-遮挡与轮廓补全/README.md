# 遮挡与轮廓补全（Occlusion and Contour Completion）

研究物体或轮廓部分被遮挡时，视觉系统如何推断连续边界、完整形态及物体结构。

## 研究内容
- 遮挡（Occlusion）
- 轮廓补全（Contour Completion）
- 非模态补全（Amodal Completion）
- 边界归属（Border Ownership）
- 轮廓整合（Contour Integration）

## 案例分析问题
1. 哪些轮廓实际可见，哪些属于知觉补全？
2. 遮挡关系是否清晰？
3. 哪些线索支持连续性和物体完整性？
4. 是否存在其他解释？

与闭合律、良好连续律及图形—背景组织相关，但不等同于单一原则。参考 Wagemans et al. (2012) 与 Palmer (1999).
