# 动态视觉组织（Dynamic Perceptual Organization）

研究视觉元素随时间发生运动、出现、消失或变化时，如何形成群组、路径和整体结构。

## 研究内容
- 运动分组（Motion Grouping）
- 共同命运（Common Fate）
- 同步（Synchrony）
- 运动定义轮廓（Motion-defined Contours）
- 动态图形与背景组织
- 动态形态变化与时间连续性

## 案例分析问题
运动方向、速度和时间关系分别如何？运动是否建立群组或因果暗示？动画是否造成注意竞争？静态截图是否足以解释现象？

设计边界：同步高亮不等于因果关系，避免无依据的因果暗示。参考 Wagemans et al. (2012) 与 Palmer (1999).
