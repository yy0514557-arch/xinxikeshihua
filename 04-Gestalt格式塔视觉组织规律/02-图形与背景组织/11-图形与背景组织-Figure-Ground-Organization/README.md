# 图形与背景组织（Figure-Ground Organization）

> 研究编号：11｜分类：02-图形与背景组织｜状态：理论工作定义，待案例验证

## 一、定义（Definition）
视觉系统倾向于将视觉场组织为图形主体与其背景，并对两者之间的边界进行知觉分配。

## 二、理论概念与研究重点（Concept）
研究主体/背景分离、边界归属、面积、包围、对称和熟悉性。用于视觉焦点、负形和信息层级；图底可能反转。

## 三、形成条件与观察线索
记录元素距离、形状、颜色、方向、边界、运动、遮挡、背景和任务情境等实际条件。说明其他线索是否同时存在，不将单一线索视为绝对规则。

## 四、经典示意与案例方向
研究主体/背景分离、边界归属、面积、包围、对称和熟悉性。用于视觉焦点、负形和信息层级；图底可能反转。

undefined

## 六、信息图形应用
检查该原则如何影响分类识别、数据系列区分、阅读路径、模块分组、图例理解和视觉层级。说明它承担的是数据编码、结构组织还是辅助装饰。

## 七、适用边界与常见误用
不得将视觉倾向写成必然结果；不得把设计转译当成心理学实验结论。结合受众、媒介、文化和具体视觉条件说明边界。

## 八、与其他原则的关系
案例分析时记录协同、竞争和冲突线索。相关原则不因名称相近就合并，也不因独立建档就认定理论上完全独立。

## 九、证据状态
- 可见观察（Observation）：画面中可直接观察的事实。
- 理论解释（Interpretation）：与理论概念的对应。
- 设计推断（Design Inference）：可检验的设计解释。
- 待核查事项（To Verify）：来源、条件或替代解释尚不明确之处。
