# 04｜Gestalt 格式塔视觉组织规律

**Gestalt Principles and Perceptual Organization**  
版本：v1.0｜定位：视觉感知与组织规律研究库

## 研究定位
研究人类如何组织视觉信息，包括元素分组、图形与背景分化、形态补全、整体组织，以及经验、情境和注意等影响因素。服务于平面设计、信息设计、信息图形和交互可视化。

**分类边界：** Gestalt 不是信息图形类型，也不是单一设计风格。不同文献对原则数量、名称及层级并不完全一致。本目录的条目数量是仓库采用的工作分类，不宣称为学界统一定数。

## 研究层级
1. 视觉分组原则：研究视觉元素如何形成群组。
2. 图形与背景组织：研究主体与背景的分化及其影响因素。
3. 形态完整与整体组织：研究闭合、轮廓补全与简洁组织。
4. 知觉影响因素：研究经验、预期、情境和注意对知觉的影响。

## 单项原则记录规范
每项原则包含 `README.md`（定义与理论）、`案例/`（原始案例及来源）、`分析/`（观察、解释与验证）、`设计实践经验.md`（实践记录）。

每个分析必须区分可见观察、理论解释、设计推断和待核查事项。单个案例可以涉及多个原则，须说明各自作用；不能仅凭出现某种形式就断定原则成立。

## 专题研究
遮挡与轮廓补全、动态视觉组织、复合原则与交互关系跨越多个研究层级，不强行归入单一原则。
