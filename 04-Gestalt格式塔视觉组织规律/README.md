# 04｜Gestalt 格式塔视觉组织原则

> 结构参考 fengbaifan/Infographic-Style-Repository 的 Gestalt 专项目录。

## 研究定位
研究观看者如何将视觉元素组织为群组、形态、轮廓及图—底结构；不是信息图形类型、数据逻辑或统计图形分类。

## 目录
- 00-Gestalt概念与分类框架.md
- 01-规则库：12 项核心研究条目，每项仅一份 Markdown 文档
- 02-案例库：真实案例一案一档，原图不重复存储
- 03-跨原则对照实验：比较知觉线索的竞争与协同
- 04-设计实践经验汇编：跨项目记录经验、失败版本及边界
- 05-参考文献：心理学原始研究与综述优先

## 12 项核心研究条目
G01 接近律；G02 相似律；G03 良好连续律；G04 共同命运律；G05 共同区域律；G06 连接律；G07 同步律；G08 闭合律；G09 对称律；G10 平行律；G11 图底关系；G12 良好形态原则。

12 项是本项目工作目录，不是学界统一承认的固定定律总数。理论层级并不完全相同，详见总论。

## 工作约束
1. 先确认数据与叙事关系，再选择知觉线索；视觉分组不能替代真实数据关系。
2. 区分图像观察、理论解释、设计推断和用户测试结果。
3. 不杜撰案例、作者、数据、版权许可或实验结论。
4. 每个案例只在案例库保存一份，规则文档通过 CASE ID 关联。
5. 实践建议标记为待验证；没有真实测试数据，不得写成已验证结论。
6. 不把设计教育网站自行编排的条目数量当作学术界唯一分类。
