# 04｜Gestalt 格式塔视觉组织规律

**版本：V2.0｜定位：视觉知觉组织理论与信息设计应用研究库**

Gestalt 研究视觉系统如何将局部刺激组织为群组、轮廓、形状、表面及图—底关系。它不是信息图形类型、统计图形或单一视觉风格。

- 01-规则库/：12 项核心研究条目 G01–G12；9 项扩展研究因素 E01–E09
- 02-案例库/
- 03-跨原则对照实验/
- 04-设计实践经验汇编/
- 05-参考文献/

## 分类声明
12 项核心、9 项扩展是本知识库的工作分类，不是学界公认的固定总数。扩展因素不与经典分组原则混为同一级别。G06 连接律分别说明 A 元素连接（Element Connectedness）与 B 统一连通性（Uniform Connectedness）。

## 研究纪律
1. 区分文献证据、图像观察、理论解释、设计推断和实验结果。
2. 案例必须有可追溯来源；未核实的作者、年份和数据不得补造。
3. 没有真实实验数据，不得声称实验已验证。
4. 视觉分组不等于数据关系；视觉编码不得制造虚假因果或类别关系。
5. 第三方图片权属不明时只保存来源链接，不擅自再发布原图。
