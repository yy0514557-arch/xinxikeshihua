# 01｜规则库

本库分为 12 项核心研究条目和 9 项扩展研究因素。核心条目不是学界唯一固定清单；扩展因素不与经典分组原则混为同级定律。

## 核心研究条目
G01 接近律；G02 相似律；G03 良好连续律；G04 共同命运律；G05 共同区域律；G06 连接律；G07 同步律；G08 闭合律；G09 对称律；G10 平行律；G11 图底关系；G12 良好形态原则。

## 扩展研究因素
E01 小面积因素；E02 包围性；E03 凸性；E04 下方区域因素；E05 上下极性因素；E06 过去经验；E07 知觉定势；E08 情境影响；E09 注意机制。

## G06 子机制
- A 元素连接（Element Connectedness）：元素之间通过线或连接符建立联系。
- B 统一连通性（Uniform Connectedness）：区域内部颜色、亮度或纹理等属性连续统一。
两者分别定义、分别收录案例，不得混为同一概念。

每条规则须含定义、理论身份、观察线索、设计应用、边界、关系、案例索引和参考文献。理论定义与设计推断必须分开。
