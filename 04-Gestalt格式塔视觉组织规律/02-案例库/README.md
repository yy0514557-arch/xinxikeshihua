# 02｜案例库

## 目的
集中保存格式塔心理学实验、平面设计、信息图形、字体版式、界面交互和综合案例。案例材料一案一档，规则文档只通过 CASE ID 引用。

## 推荐结构
- 01-经典格式塔心理学实验
- 02-平面设计案例
- 03-信息图形设计案例
- 04-字体与版式案例
- 05-界面与交互案例
- 06-综合案例
- 案例分析模板.md
- 案例索引.md

每个正式案例采用 CASE-0001-短名称，至少含 README.md、分析.md、原图来源.md。原图仅在有权保存和再发布时上传；权属不明时保留官方链接。

## 收录标准
1. 来源可追溯，优先原始论文、作者/机构官网和出版方页面。
2. 区分真实实验原图、设计作品和教学示意图。
3. 图面线索必须可复核。
4. 一个案例可关联多条原则，但只保存一份完整材料。
5. 不以数量为目标；无可靠案例时标记待补。

## 证据等级
L1 文献证据；L2 图像观察；L3 理论解释；L4 设计推断；L5 用户/实验数据。

来源核验不等于版权授权。
