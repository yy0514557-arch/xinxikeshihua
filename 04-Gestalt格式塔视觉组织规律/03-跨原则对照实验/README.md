# 03｜跨原则对照实验

比较不同 Gestalt 线索的相互支持与冲突，例如接近与相似、共同区域与接近、连线与颜色相似、闭合与连续。实验须明确自变量、控制条件、样本/任务及判定指标，不得将设计偏好写成普遍规律。

研究问题可包括：接近与相似冲突时如何分组；容器边界是否改变距离分组；连线与颜色相似如何影响关系判断；轮廓缺口大小如何影响闭合判断；图底组织中的面积、包围和边界线索如何共同作用。

最低记录：研究问题、假设、自变量及水平、因变量、控制条件、刺激材料、参与者与样本量依据、任务程序、随机化、排除标准、分析方法、结果、局限及复现材料。

当前无真实实验记录。无实测数据时不得填写正确率、反应时或显著性结果。
