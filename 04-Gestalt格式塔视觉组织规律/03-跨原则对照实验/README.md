# 03｜跨原则对照实验

## 目的
研究多种知觉线索在同一刺激中的竞争、协同或层级关系。实验用于检验明确且可反驳的问题，不用于证明设计者偏好的版式。

## 推荐专题
1. 接近律 × 相似律：距离与属性相似冲突时的分组判断。
2. 接近律 × 共同区域：距离与容器边界的相对作用。
3. 元素连接 × 相似律：连线与共同颜色对关系判断的作用。
4. 闭合律 × 良好连续律：轮廓补全与连续路径线索。
5. 图底关系 × 包围性：区域包围、边界归属和前景判断。
6. 共同命运 × 同步：共同运动与同时变化的区分。
7. 对称 × 接近/相似：多线索协同与冲突。
8. 多原则竞争与协同：依具体问题提出假设，不预设普遍排序。

## 实验最低要求
研究问题和假设、自变量及操作水平、因变量、控制条件、刺激材料、参与者与样本量依据、伦理与隐私、任务和程序、随机化/平衡、排除标准、分析方法、结果和局限。

## 结果纪律
无真实实验数据，不填写正确率、反应时或显著性。探索性小样本结果不可外推为普遍规律。主观偏好不能替代理解任务表现。

未完成实验标记“待设计”或“待实施”，不预填结果。
