# 02｜信息图形类型案例（17种市场化表现形式）

**五种基础组织逻辑是唯一的类型学分类**：编年型、层级型、编目型、字母表型、地理图型。**02 仅收录 17 种市场化表现形式标签**，服务于制作、传播和案例检索。每张作品依据主导信息关系选择一个基础主归属，可选用多个市场表现标签。

**ISOTYPE 已独立为 [02 中保留的 ISOTYPE 方法档案](./基础设计方式标签/ISOTYPE/README.md) 专项项目**，不再作为本目录的“18号标签”。

## 与独立设计方法项目的关系

本目录可在案例分析中引用独立 [02 中保留的 ISOTYPE 方法档案](./基础设计方式标签/ISOTYPE/README.md) 的方法规范，但 ISOTYPE 不作为 02 的标签编号、归档子文件夹或市场表现类型。

## 每个标签统一采用
```text
02-信息图形类型案例/
└── 标签目录/
    ├── 00-标签说明.md
    └── 案例/
        ├── README.md
        ├── CASE-0001-作品名/
        │   ├── 原图.png（有可公开归档权时）
        │   ├── 分析.md
        │   ├── 基础数据集.csv
        │   ├── 数据字典.md
        │   └── 原图来源.md（来源及权属记录）
        └── CASE-0002-作品名/
            ├── 原图.jpg
            └── 分析.md
```
示意 CASE 目录**不代表已上传案例**。每有一张原图才建立一个实际 CASE 子目录；允许多个案例，不限两个。独立原图与其分析必须存放在同一 CASE 中。

## 2026-11-20：数据集与图像权利增补

**每一 CASE 必备：** `分析.md`、`基础数据集.csv`、`数据字典.md`、原图或经核验的 `原图来源.md`。有其他非主图数值时附 `辅助指标.csv`。原则：单元格原子性、记录粒度明确、量纲一致、来源可溯，复合地理实体名仍算一个对象字段。第三方受版权保护作品未经确认再发布权限时，只引用官方图像并明确未在仓库存图，不以外链冒充原图文件。
