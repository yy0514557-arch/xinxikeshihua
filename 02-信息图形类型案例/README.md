# 02｜信息图形类型案例

本目录采用两个互补维度：**五种基础数据逻辑（唯一主归属）**与**17 种市场化表现形式（可多选标签）**。两者不在同一分类层级。

## 一、五种基础数据逻辑
- 编年型（Chronological）：时间或阶段顺序主导。
- 层级型（Hierarchical）：包含、隶属、上下位关系主导。
- 编目型（Categorical / Catalog）：类别、条目或对象集合主导。
- 字母表型（Alphabetical）：字母或约定字符顺序主导。
- 地理图型（Geographical）：真实地理位置、空间分布或地理关系主导。

定义以 [01-信息图形数据逻辑](../01-信息图形数据逻辑/) 为准。每案只能有一个基础逻辑主归属；证据不足标记待分类。

## 三、ISOTYPE
[ISOTYPE](./基础设计方式标签/ISOTYPE/README.md) 是跨类型视觉语言与设计方法，不计入 17 种表现标签，也不是第六种基础逻辑。普通图标不足以判定 ISOTYPE。

## 四、每类目录结构
每类统一包含 00-标签说明.md、README.md 和 案例/README.md。正式案例以 CASE-XXXX-作品名建立独立目录。

## 六、研究纪律
先分析数据关系，再确定基础主归属与表现标签；不从外形直接推断逻辑；不编造源数据、作者、年份、指标、坐标、制作过程或版权许可；观察、推断、待核实事项和测试结果分开记录；一个案例只存一份原图和分析。
