## 案例素材与分析

- 课件案例页码：第22–38页；第36–37页对应编年与编目混合图。
- `素材/` 用于存放从课件或用户提供来源中整理的原始案例图；`案例分析/` 存放逐张案例研究。
- 类型说明文件是分类入口和持续归纳文档；具体图片事实需在案例分析中注明来源页码。
- 每个案例按 A 数据逻辑、B 统计图形与计算、C 视觉编码、D 信息架构、E 视觉叙事分析。
- 01 目录只通过 Markdown 相对链接引用本目录的案例分析，不复制图片。
