## 每个类型文件夹的统一内容

- `README.md`：该类型的概念说明与持续更新的研究结论。
- `案例/`：该类型对应的案例图片及来源记录。
- `分析/`：逐张案例的 A–E 五维分析文档。

## 统一分析维度

A｜基本数据逻辑  
B｜统计图形与计算  
C｜视觉编码（点、线、面、体、符号、色彩等）  
D｜数据／信息架构  
E｜视觉叙事架构

案例结论须以实际图片和可核实资料为依据；区分画面观察、推断与待核实事项。01-信息图形数据逻辑目录仅通过 Markdown 相对链接引用这里的案例分析，不存放图片。
