## 二、功能文件夹

- [素材](素材/README.md)：只存放实际案例图片、原始截图及其来源说明，不重复放类型文档。
- [案例分析](案例分析)：存放逐张案例的深入分析，文件名按“类型编号-案例编号-案例名称”统一。

## 三、统一分析框架

每张案例按以下五个维度记录：

A｜基本数据逻辑  
B｜统计图形与计算  
C｜视觉编码  
D｜信息架构  
E｜视觉叙事

## 四、素材来源与分类说明

课件：《第三讲-信息图形类型学》；原课件类型页码以各类型文档和实际案例记录为准。第17类“词云图”由用户追加，不作为原课件已有分类。
