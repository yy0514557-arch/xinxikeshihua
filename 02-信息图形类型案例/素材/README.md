# 02｜素材库

本文件夹只放**实际图片素材**，不放类型说明文档，避免与 02 根目录的 01–16 文档重复。

## 文件命名规则

`编号-类型名称-案例编号-来源.扩展名`

例如：

- `11-文字可视化-案例01-课件第32页.jpg`
- `12-解剖式信息图形-案例01-课件第33页.jpg`
- `15-编年与编目混合图-案例01-课件第36页.jpg`

## 整理规则

1. 原图尽量保留，不用 Markdown 文件代替图片。
2. 一张图对应一个文件，编号与根目录类型文档一致。
3. 文件名注明课件页码或原始出处。
4. 同一类型有多张图时，依次编号为案例01、案例02……
5. 图片的文字说明和分析放在“案例分析”文件夹，不放在这里。
