## 类型说明（工作定义）

词云图通常将词语或短语作为主要视觉单元，通过文字大小、位置、方向、字重、字体和色彩等视觉变量组织词语。若文字大小或其他视觉变量映射词频、权重或重要性，必须说明数据字段、统计口径和映射规则；若仅为排版强调，则不能将其解释为定量编码。

## A｜基本数据逻辑

识别词语/短语、出现次数或权重、文本来源、分组标签及时间或对象维度。明确词频统计的分词规则、同义词合并、停用词处理、统计范围与分母。区分原始频次、归一化权重和人工强调。

## B｜统计图形与计算

检查是否使用词频、TF-IDF、主题权重或其他指标；记录计算方法、数据来源、统计窗口和筛选规则。若案例未提供这些信息，标注为待核验，不根据字号反推精确数值。词云不适合精确比较相近数值，必要时应配合频次表或条形图。

## C｜视觉编码

重点分析：
- 字号／面积：是否映射词频或权重，映射是否明确；
- 位置：是否仅为填充版面，还是表达分组、关联或层级；
- 字体、字重、方向：是否影响识读及语义强调；
- 色彩：是否表示类别、情绪、主题或仅作装饰；
- 形状边界：是否由主题轮廓限制，以及轮廓是否干扰词语比较。

区分数据编码、语义分类和纯装饰，不将所有视觉差异都解释为数据。

## D｜数据／信息架构

记录词语清洗与筛选流程、类别或主题分组、词语之间是否存在共现关系，以及标题、图例、来源、统计口径和辅助表格的组织方式。若词语只是独立排列，不应臆造网络或层级关系。

## E｜视觉叙事架构

分析读者如何进入画面、首先识别哪些关键词、如何理解字号和颜色含义，以及作品是否提供从整体主题到具体词语的阅读路径。检查视觉焦点是否与数据重要性一致，避免装饰性布局掩盖信息来源与统计含义。

## 与01数据逻辑的关联
