# 混合型信息图形 · Mixed Charts
**市场化表现形式标签：Mixed Charts**｜版本 V1.0（2026-11-19）

> **定位**：“混合型”只是在设计制作与市场沟通中方便使用的表现形式名称，**不属于第六种基础信息图形类型**。每件 Mixed Charts 必须先归属 [五大组织逻辑](../../README.md#唯一的基础类型学五种组织逻辑) 中的一类，再研究其怎样借用统计图形、符号与叙事元素。

## 概念
混合型信息图形是将**一个或多个统计图形**与**符号、文字、图像、注释、结构布局**有目的地结合，经过视觉编码与叙事设计，将数据关系转化为可阅读的信息故事。它不是简单把柱状图、饼图和图标堆在一起，也不是将原有数据可视化截图贴进海报。

- **统计层**：负责数量、差异、分布、变化和计算的准确性。
- **符号层**：用标准化图标、语义符号、产品／人物／地理图像帮助识别“数据在说什么”。
- **叙事层**：通过标题、重点数字、信息模块、视线引导、局部特写构成解释顺序。

**特别区分**：ISO 标准化图形符号与 **ISOTYPE** 式重复象形符号编码不是同一个概念。前者常用于统一识别；后者可以通过固定单位的重复图符表示数量，须声明“每符号代表多少单位”。不可因图标好看就当作已量化数据。

|---|---|---|

| [层级型](../../01-信息图形数据逻辑/02-层级型信息图形概念定义.md) | 上下级／权重等级 | 分层结构＋权重条形＋节点图标 |
| [编目型](../../01-信息图形数据逻辑/03-编目型信息图形概念定义.md) | 类别与成员归属 | 分类卡片＋分类统计图＋物品符号 |
| [字母表型](../../01-信息图形数据逻辑/04-字母表型信息图形概念定义.md) | 检索键与规则化索引 | A–Z 目录＋桶内统计＋概念小图 |
| [地理图型](../../01-信息图形数据逻辑/05-地理图形信息图形概念定义.md) | 空间定位与区域关系 | 区域地图＋符号图＋比较条形 |

**分类原则**：组合了几种图表并不决定基础类型；要看作品最先要求读者理解的**主导信息关系**。局部叠加其他组织逻辑，只作为辅助描述。

## A｜数据的本质逻辑
必须先在五类中确定主归属，再决定是否需要数值表。数据至少具有**同一问题下可共同解释的记录集合**；多个数据源应有可复核的连接键、统一口径与分析对象。统计图中的数字和象形符号应指向同一对象、单位和期间，不能各讲无关事实。

## B｜统计图形、计算及借用规则
- 组间比较：条形图、点图、小倍数；对应差值、占比、排名；排名作为局部编码时不改变基础类型。
- 时序：区间条、变化折线、节点序列；涉及间隔、变化率、累计量时按真实尺度处理。
- 构成：100% 堆叠条、点阵、象形符号数量阵列；要求可加、互斥或明确多重标签口径。
- 地理：分级设色、比例符号、区域统计；统计量须和地理键匹配。
- 不可通过图像设计推算数据，也不可用图符大小制造没有来源的量级差。

## C｜视觉编码：点、线、面、体、符号、色彩
| 通道 | 信息任务 | 设计规则 |
|---|---|---|
| 点 | 观测值、统计节点、代表物 | 统计图圆点有统一轴；示意点与数据点须分开 |
| 线 | 坐标轴、趋势、连接、引导 | 趋势线只用于数值关系；叙事引导线不冒充统计连线 |
| 面 | 比例、图表区块、内容分节 | 数据面积与数值成比例；装饰面要与统计面区分 |
| 体 | 对象插画、空间场景、三维示意 | 可增加感知，不牺牲数据读数与可比性 |
| 符号 | ISO/标准化图标、ISOTYPE式量化图符、主题隐喻 | 图例说明符号类别/量值；重复符号各单位一致 |
| 色彩 | 数据类别、强调、品牌气质 | 同一变量在图表与图符之间编码一致 |
| 文字 | 事实注释、关键数字、解释结论 | 标题负责提出问题；每个数字提供单位/来源 |

**设计顺序**：先完整数据结构和计算→再选择图表→定义图符编码→最后构建叙事版式。风格化不能改变统计关系。

## D｜数据／信息架构
最小推荐字段：`record_id`、`group_id`、`metric`、`value`、`unit`、`source`；另外用 `chart_id`、`visual_symbol`、`annotation` 管理视觉层。分类逻辑字段须遵守 01 的相应模型，非数值资料不可伪造为数值型。

信息层级：**全局论点→数据证据→符号解释→必要背景→可复核注释**。多个图形共享标题和口径，不应成为互不关联的小展板。

## E｜视觉叙事架构
**吸引读者的核心问题／数字→主证据图→图符解释“是什么”→辅助证据图→限定条件与结论**。可以有一个明显的视觉锚点，但主证据必须能被读懂而非只是被观看。

## 质量判断
1. **拿掉插画，统计关系是否仍正确？**
2. **拿掉统计图，图符是否仍能说清数据在描述什么？**
3. **所有图表合在一起，是否回答同一个问题？**
4. **基础归属是否只能从五大组织逻辑中选出？**
如有任一项不成立，需修改结构。
