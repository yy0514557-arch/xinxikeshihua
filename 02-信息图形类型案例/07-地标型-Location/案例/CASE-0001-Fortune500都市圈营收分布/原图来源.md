**版本区分：** 本次用户在对话中上传的是深青灰色底、白色地图、纽约白圆、下方带大标题和说明文字的**杂志版截图**。上方可访问的《Fortune》官方网页版本为白底、灰色地图、纽约黑圆，排序数据和主要结构一致。网页版本**不是原封不动的用户所传杂志版图片**，不得混淆。

**权利与入库状态：** 两幅作品均属于第三方公开出版的受版权保护内容。此公开 GitHub 仓库只保存版权方图像的**官方链接与网页引用**，尚未复制用户上传的杂志版 JPEG 到 Git 仓库，不宣称原始图片文件已入库。待可公开再发布的权限明确或有可上传的授权文件时，将 `原图.jpg` 放置于本案例同目录，并更新索引状态。数据转录、方法分析及来源说明均已独立入库。

**地图数据底图署名（原稿网页）**：USGS/NASA Landsat data / Orbital Horizon / Gallo Images / Getty Images。
