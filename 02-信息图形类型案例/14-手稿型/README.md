# 手稿型

**英文名称：** 课件未标英文。

**课件来源：**《第三讲-信息图形类型学》第35页。

## 案例研究

以手写文字、手绘线条、图示、箭头、注释和非机械化排布构成信息表达。手稿感首先是一种视觉语言和表现方式，不能仅凭手绘外观推断其底层数据逻辑。

## A｜基本数据逻辑

从具体案例识别其实际组织关系：可能是说明、分类、过程、空间关系或时间记录，需依据内容判断，不把“手稿型”误当作一种固定数据结构。

## B｜统计图形与计算

核对手绘图形是否承担数量表达；若有比例、数量或趋势，检查刻度、图例、单位与数据依据。手绘不等于非统计，装饰性图形也不等于数据图。

## C｜视觉编码

分析笔触、线条粗细、箭头、圈画、手写字、符号、色彩和版面路径如何引导注意；区分手绘风格与真正的数据映射。

## D｜信息架构

记录标题、分区、注释、图例、图文关系及信息先后。

## E｜视觉叙事

观察读者如何沿着手绘路径浏览，手写注释如何建立讲述语气、强调和解释。
