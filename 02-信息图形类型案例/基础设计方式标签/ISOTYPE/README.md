# ISOTYPE｜基础设计方式标签

<标签属性：基础设计方式／视觉语言体系>

**ISOTYPE 不列入 02 目录的 17 种信息图形类型。**它不是与时间轴型、比较型、流程图型等并列的一种信息图形，而是一种具有独立历史、方法与视觉语法的基础设计方式，可作为跨类型的设计方法和视觉表达体系使用。

## 标签定位

- 标签名称：ISOTYPE
- 中文名称：国际图画文字教育系统（常称 Isotype）
- 标签类别：基础设计方式／视觉语言体系
- 与信息图形类型的关系：横向关联、跨类型应用，不计入 17 种类型编号。
- 使用原则：当案例的核心视觉组织明显采用 Isotype 的图像符号化、标准化图形语言及其组织方法时，可添加此标签；仅仅出现图标或 pictogram，不足以直接判定为 Isotype。

## 研究与案例记录

- `案例/`：保存 Isotype 相关案例图像及来源记录。
- `分析/`：保存 Isotype 方法、视觉语法及案例分析。

## 分析关注点

1. 图像符号如何将对象、行动或概念转化为可识别的视觉单位。
2. 符号是否经过简化、标准化，并保持一致的视觉语法。
3. 数量如何通过重复符号、符号组或其他明确规则表达。
4. 图形的排列、分组、顺序与空间组织如何传递信息。
5. 图像、文字、数字和图例如何协同，是否支持跨语言理解。
6. 该方法如何与具体信息图形类型结合，而不是被误判为一种类型。

## 使用边界

本标签用于标记一种基础设计方法，不替代 02 中的类型标签。一个案例可以同时具有某种信息图形类型标签和 ISOTYPE 基础设计方式标签；是否适用应依据实际案例的视觉组织方式判断。
