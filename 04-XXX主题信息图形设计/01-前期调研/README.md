# 01｜前期调研

## 目标
明确为什么做、给谁看、要说明什么、信息从哪里来。

## 调研内容
1. 选题背景：社会、文化、历史、科学或地域背景。
2. 主题范围：时间、地理、对象、概念边界及排除项。
3. 受众分析：已有知识、阅读习惯、关注点和使用场景。
4. 核心问题：读者看完后应知道、理解或判断什么。
5. 信息价值：独特性、重要性、可视化潜力和传播价值。
6. 资料初查：数据、权威机构、文献、档案、图像和案例。
7. 案例调研：同主题信息图、数据新闻、展览图表、出版物与交互作品。

## 交付物
选题说明、受众描述、核心问题清单、参考案例、初步来源表、数据缺口与风险。

每条调研记录：问题、来源名称、作者／机构、发布日期、链接／出处、核心信息、可信度、可用于哪个环节。
