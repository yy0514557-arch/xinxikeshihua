# 04｜XXX主题信息图形设计

可复制的主题信息图形设计项目模板。将 XXX 替换为实际选题名称。

## 项目流程
1. 01 前期调研：主题背景、范围、受众、问题、案例。
2. 02 主题内容分析：与大模型共同判断内容结构、叙事类型、媒介风格和分层标签。
3. 03 数据搜集：公用数据集、文本文献、自建数据集。
4. 04 基础数据集构建：字段原子化，一列一个变量，一个单元格一个值。
5. 05 叙事框架搭建：组合字段，形成信息单元与叙事主线。
6. 06 视觉编码：点线面体、色彩、字体、图像、统计图形、ISO 图形，偏重设计表达。
7. 07 信息轮盘测试：先预留，方法后续补充。
8. 08 设计实施：定位、草图、线框、视觉稿、定稿、输出。

## 基本原则
- 先明确主题问题，再选择图形；不为用图表而倒推选题。
- 原始数据、清洗数据、基础主表、关联资源、叙事数据集分层保存。
- 一列对应一个明确字段；一个单元格只放一个原子值。多个标签、坐标值、图片或多段摘录应拆列或另建关联表。
- 事实、来源观点、设计解释、大模型建议分开标注；所有数据可追溯。
- 内容叙事、媒介、视觉风格、图形形式是不同层次，不混用标签。
