# 02｜主题内容分析

本阶段需要与大模型多轮沟通。大模型用于提出结构、比较方案和辅助归纳；事实、分类与数据结论必须回到可靠来源核实。

## 核心问题
- 主题核心是什么？有哪些子主题、对象、事件、过程和关系？
- 更适合编年型、编目／分类型、空间型、流程型、比较型、因果型、关系型，还是组合叙事？
- 更适合平面图形、照片、插画、文字、统计图形或混合媒介？
- 适合哪些具体标签和图形形式：词云、文字型信息图、照片型信息图、时间轴、地图、关系网络等？
- 哪些内容作为主视觉，哪些作为辅助信息？

## 必须区分的层次
1. 内容组织／叙事结构：编年、编目、空间、流程、比较、关系、因果、档案等。
2. 信息媒介：文字、数字、地图、照片、插画、图标、统计图形等。
3. 视觉风格：平面／几何、照片纪实、插画、档案编辑、数据艺术等。
4. 具体图形形式：词云、时间轴、地图、关系网络、流程图、矩阵、统计图表等。
5. 标签体系：分别标注主题、叙事、媒介、风格、图形形式。
“编年型”与“照片风格”不是同一维度；“词云图”是具体图形形式，“文字型信息图”是媒介／作品类型。

## 建议步骤
让模型复述主题并列出边界问题；拆分对象／事件／地点／时间／关系；提出 2—4 种叙事方案并比较；判断媒介与风格；形成分层标签；核实事实；形成主题分析结论。

## 交付物
内容结构图、叙事类型判断、媒介与风格判断、分层标签清单、信息层级、大模型沟通记录与人工决策依据。
