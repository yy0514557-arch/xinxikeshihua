# 06｜视觉编码

本阶段偏重设计表达。视觉编码将信息结构、数据差异和叙事重点转化为可感知的视觉语言。

## 点线面体与空间
点：对象、地点、人物、样本、节点。线：时间、路径、连接、流向、关系、边界。面：区域、分类、分组、范围、版块、密度。体：层级、体量、深度；慎用透视以免数量误读。空间组织可用网格、轴线、径向、地图、树状、分区和路径布局。

## 色彩
定义主色、辅助色、强调色、背景色、中性色，以及色彩与类别／数值／情绪／层级的关系；检查对比度、色觉差异与印刷限制。

## 文字与排版
字体、字重、字号层级、标题／正文／注释／数字／图例层级；行距、字距、段落间距、对齐；中西文混排、数字格式、单位和标点；文字密度与阅读路径。

## 图像与图形
照片（纪实、档案、人物、场景、物件）；插画（解释、概念、情境）；图标与图形符号。记录来源、版权、作者、授权和裁切规则。

## 统计图形
根据数据任务选择条形图、折线图、散点图、矩阵、箱线图、网络图、桑基图、树图、地图等。检查数据类型、统计口径、轴尺度、图例和视觉变量。

## ISO 图形与符号
记录具体标准编号、名称、适用范围、版本和授权。不可追溯到标准的普通图标不能称为 ISO 图形。

交付：视觉关键词／参考板、点线面体草图、色彩系统、字体排版规范、图像／符号规范、统计图形规范、视觉编码总表。
